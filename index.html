Token kaise banana hai? (required once)
  1. GitHub par fine-grained token create karo.
  2. Resource owner apna wahi GitHub account rakho jisme ye Codespaces bane hain. Repository access mein amffcomedy2-maker/windows select karo, agar GitHub us repository ko select karne de.
  3. Repository permissions mein Codespaces: Read-only aur Codespaces lifecycle admin: Read and write set karo. Ye status dekhne aur stopped Codespace start karne ke liye hain.
  4. Token generate karke upar wale box mein paste karo, phir Check both sessions dabao.

Security: Token ko GitHub repo mein kabhi paste/commit mat karna. Kaam khatam hone par token box clear kar do; token ko GitHub settings se revoke bhi kar sakte ho.

240 ghante tak Windows data kaise bachayein?

GitHub → Your Codespaces par original Codespace ko delete mat karna. GitHub Settings → Codespaces mein stopped Codespace ka retention period kam-se-kam 10 days rakho (default aam taur par 30 days hota hai). Aur bhi safe rakhne ke liye Codespace ke menu se Keep codespace use kar sakte ho. Storage charges/allowance apply ho sakte hain.

Repository ka Windows disk ./windows:/storage bind mount par hai. Codespace workspace bacha rahe to us disk ka data bacha rehna chahiye. Lekin RAM mein chal rahe apps/processes ka live state stop ke baad wapas nahi aata—Windows dobara boot hoga, magar usi saved disk ke saath.
